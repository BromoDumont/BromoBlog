No final das contas o PUCA me deu muito mais chaves que realmente me apresentou portas, agora preciso de um projeto que faça as pontes para que as chaves sejam usadas. As próximas realizações tem de estar voltadas para essa direção.

Acho que junto a esse momento de novo ciclo vou começar a usar mais uma mídia para registrar as coisas: o vídeo; essa é uma mídia… complexa para mim por uma série de fatores mas sinto que agora posso usá-la de forma minimamente interessante tendo em vista o propósito de registro.

A ideia inicial é fazer uma produção de oito vídeos, que vão ser publicado semanalmente, em que cada um registra a produção de um ambiente 3D que vou usar como peça para o portfolio de environment game artist. Um nono vídeo pode vir a existir para essa série caso eu realmente consiga um emprego com os projetos, porém, isso seria um extra, afinal de contas eu não sei se realmente vou conseguir um emprego né.

Porém, não sei se uso isso como objeto dos vídeos ou o desenvolvimento de um jogo sobre um florista. No final das contas vou fazer as duas coisas mas não sei se, primeiro, uso os ambientes 3D como objeto e depois falo do jogo ou se deixo os ambientes 3D completamente de lado. Parte de mim fala para deixar os ambientes 3D apenas para o portfolio voltado ao trabalho em estúdio e outra pede para que eu fale sobre as duas coisas.

Qualquer uma das abordagens pedem tempo de produção, vou tentar ouvir os sussurros da alma durante o processo e seguir a direção apontada por eles.
